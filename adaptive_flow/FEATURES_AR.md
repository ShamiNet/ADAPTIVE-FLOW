# أدوات إضافية للمحرر

افتح زر **أدوات +21** أعلى النافذة، ثم اختر الأداة أو ابحث عنها داخل اللوحة.
التعديلات الجماعية تشمل كل الخطوات، بما فيها الخطوات المخفية بالبحث والمعطلة.
يمكن التراجع عن التعديلات عبر زر «تراجع»، وتُحفظ تلقائياً بالطريقة المعتادة.
التصدير ينتج ملفاً مستقلاً؛ التراجع لا يحذف الملفات المصدّرة.

1. تفعيل جميع الخطوات.
2. تعطيل جميع الخطوات.
3. حذف الخطوات المعطلة.
4. عكس ترتيب الخطوات.
5. نقل الخطوة المحددة إلى بداية السيناريو.
6. نقل الخطوة المحددة إلى نهايته.
7. إدراج انتظار قابل لضبط المدة قبل الخطوة المحددة.
8. إدراج انتظار قابل لضبط المدة بعدها.
9. إنشاء 1–100 نسخة إضافية مستقلة من الخطوة المحددة.
10. استبدال نص في الأوصاف وقيم الإدخال، مع مطابقة حالة الأحرف.
11. إضافة بادئة لجميع أوصاف الخطوات.
12. توحيد التأخير اللاحق للخطوات بالمللي ثانية.
13. توحيد مدة الخطوات بالمللي ثانية؛ معنى المدة يعتمد على نوع الإجراء.
14. إزاحة الإحداثيات المكانية وأهداف السحب بمقدار X وY؛ محددات الصور وUIA لا تتغير.
15. استبدال عنوان نافذة بمطابقة كاملة؛ يشمل حقل عنوان النافذة/جهة الاتصال.
16. إلحاق خطوات ملف JSON آخر بمعرّفات جديدة مع الحفاظ على بيانات السيناريو الحالي.
17. تصدير الخطوات المفعلة فقط إلى سيناريو JSON بمعرّف مهمة جديد.
18. تحرير ملاحظات السيناريو وحفظها ضمن metadata.
19. تحرير وسوم مفصولة بفواصل إنجليزية مع حذف التكرارات والفراغات.
20. معاينة تسلسل الإجراءات والقيم والتوقيتات والمعطّل منها دون التنفيذ.
21. تصدير CSV يدعم العربية والأسطر المتعددة ويحمي الحقول النصية من تفسيرها كصيغ.

المعاينة تعرض التوقيتات المضبوطة، ولا تتنبأ بالمدة الفعلية لانتظار النوافذ أو البرامج.
تصدير CSV والمعاينة يتضمنان قيم الإدخال كما هي.
