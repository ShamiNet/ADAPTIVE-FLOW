# واجهة Adaptive Flow

شغّل `start_gui.bat` من مجلد المشروع أو نفّذ:

```powershell
.venv\Scripts\python.exe -m adaptive_flow.gui
```

1. سمِّ المهمة واختر نوع الإجراء.
2. للنقر أو تحريك الماوس: اضغط «التقاط مكان من الشاشة». تصغر الواجهة؛ انقر الموقع المطلوب، ثم تعود الواجهة. هذه نقرة فعلية تصل أيضاً إلى التطبيق. يمكن إدخال X وY يدوياً بدلاً منها. Esc يلغي الالتقاط.
3. أدخل النص أو الرابط الكامل أو اختر برنامجاً بصيغة exe حسب الإجراء. الكتابة تتم في الحقل النشط؛ أضف نقرة على الحقل قبلها. الاختصارات تستخدم صيغة مثل `{Ctrl}a` و`{Enter}`.
4. للتحكم بنافذة، أدخل جزءاً مميزاً من عنوانها؛ يتوقف التنفيذ إذا طابق أكثر من نافذة. الإغلاق يرسل طلب إغلاق عادي وقد يظهر حوار حفظ تابع للبرنامج.
5. اضغط «إضافة خطوة». لتعديل خطوة، حددها ثم اضغط «تحديث المحددة». استخدم الأسهم للترتيب و«نسخ» للتكرار.
6. «حفظ باسم» ينشئ ملف JSON يمكن إعادة فتحه. الخطوات المضافة أو المحدثة تحفظ تلقائياً في `storage/editor_autosave.json` وتستعاد عند بدء الواجهة. تعديلات الحقول لا تصبح خطوة محفوظة إلا بعد الإضافة أو التحديث.
7. «تشغيل» يصغر الواجهة ويبدأ بعد ثلاث ثوانٍ. F8 أو Esc يمنع بدء خطوات أخرى ويلغي الانتظار فوراً؛ إجراء نظام بدأ بالفعل ينتهي أولاً. تعود الواجهة عند الانتهاء ويظهر سجل التنفيذ أسفلها.

الإجراءات: نقر يسار/يمين/مزدوج، تحريك المؤشر، كتابة، اختصارات لوحة المفاتيح، انتظار، تمرير، فتح رابط، فتح برنامج ومعاملاته، تنشيط وتصغير وتكبير واستعادة وإغلاق نافذة.

المحرر ينفذ الخطوات المحلية مباشرة، بما فيها مواضع الشاشة التي اخترتها؛ لا يستدعي Gemini تلقائياً. لا يسجل جلسة كاملة تلقائياً، ولا يضيف السحب والإفلات حالياً. الإحداثيات مطلقة وقد تحتاج إلى إعادة التقاطها عند تغيير موضع النافذة أو دقة الشاشة. خطوات UIA والقوالب الموجودة في ملفات المهام تظل قابلة للتشغيل.
